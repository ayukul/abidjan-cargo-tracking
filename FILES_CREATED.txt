DATABASE SCHEMA
================================================================================

Users Table:
  - id (TEXT PRIMARY KEY)
  - email (TEXT UNIQUE)
  - password_hash (TEXT)
  - name (TEXT)
  - role (TEXT)
  - created_at (DATETIME)

Shipments Table:
  - id (TEXT PRIMARY KEY)
  - tracking_code (TEXT UNIQUE)
  - customer_name (TEXT)
  - customer_phone (TEXT)
  - customer_email (TEXT)
  - origin (TEXT)
  - destination (TEXT)
  - current_status (TEXT)
  - estimated_arrival_date (TEXT)
  - notes (TEXT)
  - created_at (DATETIME)
  - updated_at (DATETIME)
  - created_by (FOREIGN KEY)

Status History Table:
  - id (TEXT PRIMARY KEY)
  - shipment_id (FOREIGN KEY)
  - status (TEXT)
  - note (TEXT)
  - created_at (DATETIME)
  - created_by (FOREIGN KEY)

Indexes: 6 (for performance optimization)

================================================================================
WHAT'S DIFFERENT FROM CLOUD VERSION
================================================================================

Cloud Version (Supabase):
  - Uses PostgreSQL (Supabase)
  - Uses Supabase Auth
  - Multiple external services
  - Complex setup (30+ minutes)
  - Monthly subscription cost
  - Data stored on Supabase servers
  - Not portable

Local Version (SQLite):
  - Uses SQLite 3
  - Uses iron-session
  - Zero external services
  - Simple setup (2 minutes)
  - Free
  - Data stored locally
  - Fully portable
  - Works offline
